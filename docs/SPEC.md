# 影厅清场交班轨数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `seats` | 总座数 | 席 | 85–320 |
| `filled` | 本场上座 | % | 9–99 |
| `spill` | 报告污渍点 | 处 | 0–27 |
| `minutes` | 片尾结束至下一场 | min | 12–48 |
| `bins` | 厅外垃圾桶 | 个 | 1–12 |
| `stairs` | 清理阶梯 | 级 | 5–48 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。实绩单位为分钟。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 排片座席 | `licensed_seats` | 核定座数 | 1 | 0 |
| 排片座席 | `attendance_basis` | 实上座万分数 | 100 | 0 |
| 场内巡查 | `floor_spills` | 上报溅污点 | 1 | 0 |
| 场内巡查 | `before_next_seconds` | 距开下一场秒数 | 60 | 0 |
| 保洁交班 | `waste_units` | 垃圾桶数 | 1 | 0 |
| 保洁交班 | `stairs_to_mop` | 清扫台阶数 | 1 | 0 |

示例见 `sample_data/show_handoffs_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[2,40)`、校准 `[43,62)`、回放 `[65,83)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `people` | 本场人数 | `seats*filled/100` |
| `spill_load` | 单桶污渍压力 | `spill/(bins+1)` |
| `release_pace` | 交班节奏 | `seats*filled/(100*minutes)` |
| `stair_paths` | 楼梯移动压力 | `stairs*(1+spill/30)` |
| `contamination` | 污渍与人流交互 | `spill*(1+filled/100)` |

### 指数平滑与分厅残差

按场次日期更新全体时长水平，基于历史强度残差拟合斜率。低频厅残差向零收缩。

本工作台的独立样本校准方式为按场间空档校正误差。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分位位移。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 复排清场窗口

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `NARROW_CLEAR_WINDOW` | `minutes <= 16 and filled >= 81` | 两场间隔不足 |
| 2 | `STAIR_EXTRA` | `stairs > 28 and spill > 16` | 需双人清理阶梯 |
| 3 | `BAG_CAPACITY` | `bins <= 3 and filled > 71` | 垃圾桶先补袋 |

第一条为暂停规则。其余命中与模型阈值 `15` 共同决定是否列入候选。单据所需工位数按 `1 + int(seats >= 220) + int(spill >= 18)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 清场倒排窗口

以片尾为起点预留 2 分钟开门验收时间，按袋耗、内厅、阶梯和模型工时倒排。本批同影厅的候选都按同一相对时轴演练，交叠清单用于通知班组核对实际开场时刻。 在派发环节展开现场安排，或从关联单据回查实际读数。

## 估时区间方案（区间治理）

工作台在每班次开始时一次性决定当班采用哪套估时区间，整班不允许按单切换。

### 校准与回放隔离

- 全馆区间用校准窗 `[43,62)` 的全部成熟实绩，经现有 `cleaning_overrun_bound` 模型拟合双侧区间。
- 分组区间按 `cohort`（影厅组）分别用同窗同模型校准；组成年校准实绩少于 6 条、或无法形成区间参数的组不具备分组资格，回落全馆区间。
- 两套区间只用同一批回放窗 `[65,83)` 成熟场次回放对比。校准、回放、当班三窗单号集合必须互不相交，重叠即拒绝计算，防止回放或当班样本泄漏到校准。

### 方案切换守卫

按以下守卫逐条核对，任一不通过即整班沿用全馆区间：

1. **少拦按时场次**：分组方案的回放误拦总数必须严格少于全馆方案；持平不算收益。
2. **不得多漏放超窗场次**：任一影厅组在分组方案下的漏放数高于全馆方案即否决。
3. **当班各组均有回放实绩**：当班会出现的影厅组若在回放窗没有任何成熟实绩，沿用全馆区间。
4. 缺成熟校准实绩的组允许回落全馆区间，但回落不影响整班决策的一致性。

### 拦截规则与工位

- 清场空档 = `minutes − 2`（预留 2 分钟开门验收）。区间上界大于清场空档即触发 `INTERVAL_OVER_CLEAR_GAP`，处置为「拦截」。
- 硬规则 `NARROW_CLEAR_WINDOW` 仍优先于区间拦截；拦截单不进入候选队列、不占用保洁工位，工位额度只由已分派单消耗。
- 区间不确定（`uncertain`）的单不做区间拦截，转既有「人工判读」流程。
- 选定方案同时用于分派与导出凭证：策略指纹纳入区间方案标识，凭证 `policy_hash` 随方案变化。

### 工作台核对

区间治理环节登记：选定方案与切换说明、四条守卫的通过情况、逐组校准资格、全馆与分组两套回放的逐组「拦下 / 误拦按时 / 漏放超窗 / 实绩超窗」计数，以及当班被区间红线标记的单号。回放实绩未成熟的组显式标注「未到实绩回报时间」，不以零误差替代。
